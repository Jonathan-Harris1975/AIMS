Blotato resilience changes:
- Uses JSON response format for Blotato short-pack generation where supported.
- Repairs malformed model JSON, then falls back to a deterministic short pack if repair fails.
- Extends Blotato video render polling to 480 attempts at 5 seconds, with a final grace check.
- Logs long-running render polling progress.
- Retries transient Blotato API failures: 408, 425, 429, 5xx, network and timeout errors.
- Publishes platforms independently with Promise.allSettled.
- Completes the job as partial when at least one platform succeeds, unless BLOTATO_REQUIRE_ALL_CHANNELS=true.
- Keeps Facebook in the default Blotato channel list.

RSS rewrite resilience changes:
- Removes contradictory prompt wording that encouraged the banned phrase 'worth watching'.
- Restores realistic summary bounds in env defaults: MIN_SUMMARY_CHARS=300, MAX_SUMMARY_CHARS=850.
- Adds one validation-repair pass for over-long summaries, banned filler, metadata labels, and title/summary formatting defects before quarantine.
- Adds quarantine fallback rotation: if dropped/quarantined items exceed RSS_QUARANTINE_FALLBACK_THRESHOLD, the pipeline advances to the next feed batch.
- Attempts up to RSS_REWRITE_BATCH_ADVANCE_ATTEMPTS batches before publishing accumulated safe items or failing closed.
- Quarantined items are still never published.
