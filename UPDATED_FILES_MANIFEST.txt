Koyeb build-stage fix - updated files only

Root cause from logs:
- package-lock.json contained sandbox/internal OpenAI Artifactory tarball URLs for supertest and related packages.
- External builders such as Koyeb/GitHub cannot fetch those internal URLs, causing npm ci to time out during the build/install stage.

Updated files:
- .npmrc
- .github/workflows/ci.yml
- Dockerfile
- nixpacks.toml
- package.json
- package-lock.json
- services/blotato/utils/autoPublishService.js

Key changes:
- Replaced all internal Artifactory package-lock resolved URLs with public npm registry URLs.
- Moved supertest back to devDependencies so Koyeb production installs omit test-only packages.
- Added .npmrc to pin npm installs to https://registry.npmjs.org/.
- Dockerfile now copies .npmrc before npm ci and uses Node 22.
- nixpacks.toml now uses nodejs_22.
- GitHub Actions sanity now uses Node 22 and explicitly sets the public npm registry before npm ci.
- Blotato publish-now result keeps a source alias for existing tests/status consumers.
