AIMS Zernio social-performance monthly report update

Purpose
- Adds an analysis-only monthly Zernio social performance report.
- Keeps OneUpApp and Blotato as publishing engines.
- Stores report.html, report.json, summary.json and latest.json under the Cloudflare R2 audits bucket.
- Explicitly marks the report as analysis_only so RAMS should not treat it as a repo patch source.

New route
- GET  /audits/social-performance/health
- POST /audits/social-performance/run

Recommended monthly trigger
- Trigger POST /audits/social-performance/run once per month after social metrics have settled.
- Default date range is the previous full calendar month.
- Optional body override:
  {
    "fromDate": "2026-06-01",
    "toDate": "2026-06-30"
  }

Expected output location
- audits/social-performance/<timestamp>-<sessionId>/report.html
- audits/social-performance/<timestamp>-<sessionId>/report.json
- audits/social-performance/<timestamp>-<sessionId>/summary.json
- audits/social-performance/latest.json

Required Koyeb secrets/envs
- ZERNIO_META_API_KEY        # Facebook + Instagram account
- ZERNIO_VIDEO_API_KEY       # YouTube + TikTok account
- Existing R2 audits envs must remain set:
  R2_BUCKET_AUDITS
  R2_PUBLIC_BASE_URL_AUDITS
  R2_ACCESS_KEY_ID
  R2_SECRET_ACCESS_KEY
  R2_ENDPOINT

Optional envs
- ZERNIO_META_PLATFORMS=facebook,instagram
- ZERNIO_VIDEO_PLATFORMS=youtube,tiktok
- ZERNIO_API_BASE_URL=https://zernio.com/api/v1
- ZERNIO_ANALYTICS_SOURCE=all
- ZERNIO_ANALYTICS_PAGE_SIZE=100
- ZERNIO_ANALYTICS_MAX_PAGES=12
- ZERNIO_ANALYTICS_TIMEOUT_MS=20000
- ZERNIO_REPORT_NAME=Jonathan Harris Monthly Social Performance Report
