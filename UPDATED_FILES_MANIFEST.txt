AIMS Koyeb build unblock - truncated env paste-file hardening

Confirmed findings:
- The latest narrowed Blotato/state env group validates and does not fail local build or deploy smoke.
- The checked-in AIMS Koyeb bulk paste files contained unresolved literal three-dot truncation markers from the spreadsheet/export layer.
- The previous env doctor only caught the truncated Blotato template ID and allowed other truncated paste-ready values through.
- Build validation did not scan repository Koyeb env paste files, so bad env artefacts could still ship.

Key fixes:
- Generic truncated env values containing literal three-dot markers are now rejected.
