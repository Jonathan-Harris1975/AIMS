# Phase 5 Organic Growth Gates

Use this skill pack for Jonathan Harris ecosystem automation that improves organic ebook conversion and visual social content quality without paid ads or manual review.

## Active lanes

- **5A: Organic ebook conversion posts** using copywriting, copy-editing, marketing-psychology and product-marketing-context.
- **5B: Organic FB/IG/TikTok visual content** using social-content, ai-social-media-content, social-media-carousel, og-image-design, ai-image-generation, image-upscaling and content-repurposing.
- **5C: Accessibility + Mobile UX audit enhancement** using accessibility-audit in the rendered Mobile UX pipeline.

## Fail-closed rules

- Never schedule an ebook post unless the exact book title and URL are present and validated.
- Never use fake urgency, paid-ad language, fake scarcity, unverified metrics, invented reviews, or hard-sell copy.
- Organic visual prompts must preserve the brand aesthetic and avoid cluttered, tiny-text infographic output.
- TikTok photo posts are allowed only as organic visual/content repurposing, not as paid promotion.
- Paid ads, analytics-tracking, programmatic SEO, cold email and lead magnets are parked for now.
