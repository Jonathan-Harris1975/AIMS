# Phase 3 autonomous content skill pack

Represents the Phase 3 Lane 2 skills: `copywriting`, `copy-editing`, `content-strategy`, `product-marketing-context` and `brand-guidelines`.

## Operating mode

Auto-review, auto-publish, fail-closed.

Content may publish without manual review only when the deterministic Phase 3 gates pass:

- brand tone
- British English
- source integrity
- SEO/GEO/AEO structure
- readability and TTS suitability
- image prompt constraints
- social contract checks where relevant

## Failure behaviour

If any hard gate fails, the content must be quarantined and must not update public HTML, manifests or RSS feeds.

## Brand lock

Use a British, sceptical, practical Jonathan Harris tone. Avoid hype, corporate filler, invented facts, unsupported claims and generic artificial intelligence sludge.
